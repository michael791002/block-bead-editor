# 🧩 積木拼豆編輯器 Block Bead Editor

一個以 HTML / CSS / JavaScript 製作的積木拼豆圖案編輯器。

主要用來手動設計積木拼豆圖案，支援整格與半格排列、框選編輯、顏色管理、畫布輔助、JSON 專案存取，以及 PNG 圖片輸出。

目前仍持續開發與調整中。

## ✏️ 基本操作

### 🖌️ 上色

選擇 **✏️ 上色**，再從色盤選擇顏色。

點擊畫布即可放置拼豆，按住滑鼠拖曳可以連續繪製。

如果點擊已存在的拼豆，會直接將它更換成目前選擇的顏色，不需要先擦除再重新放置。

在上色模式下也可以使用 **滑鼠右鍵快速擦除**。

### 🧽 擦除

選擇 **擦除** 後，點擊或拖曳拼豆即可刪除。

在「上色」與「填滿」模式時，也可以直接使用：

**滑鼠右鍵 → 擦除**

不需要另外切換工具。

### 🪣 填滿

使用填滿工具可以快速更換相連區域的顏色。

選擇想要的顏色後，再點擊要填滿的區域即可。

### 🎯 吸色

點擊畫布上已有的拼豆，即可取得該拼豆的顏色。

吸取完成後會自動切回上色工具。

---

## 🧩 整格與半格

編輯器支援兩種拼豆吸附模式。

### 整格

拼豆按照正常格線排列。

這也是目前的預設模式。

### 半格

拼豆可以偏移 **0.5 格** 放置。

因此可以製作一般整格排列無法完成的交錯結構。

可隨時從「其他設定」中的「吸附」切換：

```text
整格
半格
```

也可以使用快捷鍵：

```text
1 = 整格
2 = 半格
```

---

## 🎨 顏色

編輯器內建 **15 種基礎顏色**。

也可以使用 **自訂色** 開啟系統選色器，選擇其他顏色。

非基礎色會自動加入 **最近使用** 色盤。

- 最多記錄 10 種自訂顏色
- 相同顏色不會重複加入
- 再次使用的顏色會優先排列
- 可以直接點擊最近使用的顏色再次使用
- 最近使用色會保存在瀏覽器中

## ⬚ 框選操作

切換到 **框選** 工具後，在畫布上拖曳即可建立選取範圍。

選取拼豆後可以：

- 上下左右移動
- 滑鼠直接拖曳選取內容
- 複製
- 刪除
- 水平翻轉
- 垂直翻轉

滑鼠移到選取框內時，可以直接拖曳整個選取內容。

在選取框外點擊會取消目前選取；在框外重新拖曳則可以建立新的選取範圍。

如果移動後會與未選取的拼豆發生衝突，該位置將不允許放置。

方向鍵可做精細調整：

- `方向鍵`：移動 0.5 格
- `Shift + 方向鍵`：移動 1 格

## 📐 畫布尺寸與 Trim

### 調整畫布尺寸

點擊 **其他設定** 後，可以直接修改：

```text
寬 [30]   高 [30]   [套用尺寸]
```

- 增加寬度時，會從右側增加空間
- 增加高度時，會從下方增加空間
- 縮小畫布時，如果被裁掉的區域沒有拼豆，會直接套用
- 如果被裁掉的區域有拼豆，系統會先提示確認
- 尺寸調整可以 Undo / Redo

### ✂️ Trim

Trim 可以直接把作品四周未使用的空白裁掉，讓編輯畫布縮到實際作品大小。

可以選擇保留：

```text
0 / 1 / 2 / 5 格
```

例如只想保留作品外圍 1 格空白，就選擇：

```text
Trim 留白：1
```

再按 **✂ Trim**。

Trim 也可以使用 Undo / Redo 還原。

## 📏 畫布輔助與設定

點擊右上角 **⚙ 設定**，可以調整不需要頻繁操作的顯示與偏好設定。

### 畫布輔助

可獨立開關：

- 顯示中心線
- 顯示每 N 格標記
- 標記間隔：5 / 10 / 20 格
- 中心座標模式

### 格數標記

預設使用一般拼豆較直覺的格數顯示方式：

```text
5   10   15   20 ...
```

### 中心座標模式

開啟 **中心座標** 後，標記會改成以畫布中心為 `(0,0)` 的座標模式：

```text
-10   -5   0   5   10
```

座標方向為：

- 右：`+X`
- 左：`-X`
- 上：`+Y`
- 下：`-Y`

這個模式較適合需要以中心進行對稱或座標定位的設計。

### 外觀與語言

設定面板內也可以切換：

- 淺色 / 暗色主題
- 繁體中文 / English

## 💾 JSON 專案

### 匯出 JSON

點擊：

**其他設定 → 匯出 JSON**

可以先輸入檔案名稱，再將目前作品儲存成 JSON。

副檔名 `.json` 會自動加入。

JSON 會保存目前專案的重要資料，例如：

- 畫布尺寸
- 拼豆位置
- 拼豆顏色
- 整格 / 半格設定
- 畫布中心線設定
- N 格標記設定
- 中心座標設定
- 標記間隔
- 色盤相關資料

適合用來保存尚未完成的作品，之後可以重新載入繼續編輯。

### 載入 JSON

點擊：

**其他設定 → 載入 JSON**

選擇之前儲存的 JSON，即可重新載入作品並繼續編輯。

## 🖼️ PNG 圖片輸出

點擊：

**其他設定 → 匯出 PNG**

輸出前可以設定：

- 檔案名稱
- 自動裁切 / 完整畫布
- 外圍留白
- 透明 / 白色 / 黑色 / 自訂背景
- 輸出倍率
- 是否顯示格線
- 是否保留拼豆立體效果
- 是否顯示使用顏色與顆數
- 顏色統計放在左側 / 右側 / 下方 / 自動判斷
- 是否顯示 HEX 色碼

預設會依照實際使用到的拼豆範圍自動裁切。

因此即使建立 30 × 30 畫布，但只有其中一部分有使用，也不會強制輸出整個空白畫布。

## ⌨️ 快捷鍵

### 工具

| 功能 | 快捷鍵 |
| --- | --- |
| ✏️ 上色 | `D` |
| 🧽 擦除 | `E` |
| 🪣 填滿 | `F` |
| 🎯 吸色 | `I` |
| ⬚ 框選 | `S` |
| ↩️ Undo | `Ctrl + Z` |
| ↪️ Redo | `Ctrl + Y` |
| ❓ Help | `?` |

macOS 可使用 `⌘` 取代 `Ctrl`。

### 吸附

| 功能 | 快捷鍵 |
| --- | --- |
| 整格吸附 | `1` |
| 半格吸附 | `2` |

### 框選操作

必須先選取至少一顆拼豆。

| 功能 | 快捷鍵 |
| --- | --- |
| 左移 0.5 格 | `←` |
| 右移 0.5 格 | `→` |
| 上移 0.5 格 | `↑` |
| 下移 0.5 格 | `↓` |
| 左移 1 格 | `Shift + ←` |
| 右移 1 格 | `Shift + →` |
| 上移 1 格 | `Shift + ↑` |
| 下移 1 格 | `Shift + ↓` |
| 複製選取 | `Ctrl + D` |
| 刪除選取 | `Delete` / `Backspace` |
| 水平翻轉 | `H` |
| 垂直翻轉 | `V` |
| 取消選取 | `Esc` |

macOS 的複製選取可使用 `⌘ + D`。

> 在輸入檔名、畫布尺寸或操作下拉選單時，編輯器快捷鍵不會誤觸。

## 📱 手機使用

介面會依照螢幕寬度自動調整，因此可以直接使用手機瀏覽器開啟。

目前手機版會自動整理工具列與顏色色盤，盡量保留更多畫布空間。

窄螢幕下，底部的滑鼠位置 / 拼豆總數狀態列會自動隱藏；需要查看顏色與顆數時，可切換到 **統計** 分頁。

由於手機通常沒有滑鼠右鍵與實體鍵盤，因此部分桌面快捷操作在手機上不適用，主要透過畫面上的工具按鈕操作。

如果手機或平板有外接鍵盤，也可以使用快捷鍵。

👉 **[使用手機開啟積木拼豆編輯器](https://michael791002.github.io/block-bead-editor/)**
