# 🧩 積木拼豆編輯器 Block Bead Editor

一個以 HTML / CSS / JavaScript 製作的積木拼豆圖案編輯器。

主要用來手動設計積木拼豆圖案，支援整格與半格排列、框選編輯、顏色管理、JSON 專案存取，以及 PNG 圖片輸出。

目前仍持續開發與調整中。

## ✨ 主要功能

- 🖌️ 拼豆上色
- 🧽 擦除拼豆
- 🪣 區域填滿
- 🎯 吸取既有拼豆顏色
- ⬚ 框選與移動
- 🧩 整格 / 半格吸附
- 🎨 15 種基礎顏色
- 🎨 自訂顏色
- 🕘 最多記錄 10 種最近使用的自訂顏色
- ↩️ Undo / Redo
- 📂 JSON 專案載入
- 💾 JSON 專案匯出
- 🖼️ PNG 圖片匯出
- 📊 使用顏色與拼豆數量統計
- 🌙 淺色 / 暗色主題
- 🌐 繁體中文 / English
- 📱 響應式介面，可於桌面與手機瀏覽器使用

# 🚀 使用方式

本專案為純前端網頁，不需要安裝額外程式。

直接開啟網站即可開始使用。

如果下載原始檔，也可以直接使用瀏覽器開啟：

```text
block_bead_editor_v14.html
```

---

# ✏️ 基本操作

## 上色

選擇 **✏️ 上色**，再從色盤選擇顏色。

點擊畫布即可放置拼豆，按住滑鼠拖曳可以連續繪製。

如果點擊已存在的拼豆，會直接將它更換成目前選擇的顏色。

在上色模式下也可以使用 **滑鼠右鍵快速擦除**。

---

## 🧽 擦除

選擇 **擦除** 後，點擊或拖曳拼豆即可刪除。

在「上色」與「填滿」模式時，也可以直接使用：

**滑鼠右鍵 → 擦除**

不需要另外切換工具。

---

## 🪣 填滿

使用填滿工具可以快速更換相連區域的顏色。

選擇想要的顏色後，再點擊要填滿的區域即可。

---

## 🎯 吸色

點擊畫布上已有的拼豆，即可取得該拼豆的顏色。

吸取完成後會自動切回上色工具。

---

# 🧩 整格與半格

編輯器支援兩種拼豆吸附模式。

### 整格

拼豆按照正常格線排列。

這也是目前的預設模式。

### 半格

拼豆可以偏移 **0.5 格** 放置。

因此可以製作一般整格排列無法完成的交錯結構。

可隨時從「吸附」設定切換：

```text
整格
半格
```

---

# 🎨 顏色

編輯器內建 15 種基礎顏色。

也可以使用 **自訂色** 開啟系統選色器選擇其他顏色。

非基礎色會自動加入：

**最近使用**

最多記錄 **10 種自訂顏色**。

重複使用相同顏色不會產生重複項目，最近使用的顏色會優先排列。

---

# ⬚ 框選操作

切換到 **框選** 工具後，在畫布上拖曳即可建立選取範圍。

選取拼豆後可以：

- 上下左右移動
- 滑鼠直接拖曳選取內容
- 複製
- 刪除
- 水平翻轉
- 垂直翻轉

滑鼠移到選取框內時，可以直接拖曳整個選取內容。

在選取框外點擊會取消目前選取；在框外重新拖曳則可以建立新的選取範圍。

如果移動後會與未選取的拼豆發生衝突，該位置將不允許放置。

---

# 💾 JSON 專案

## 匯出 JSON

點擊：

**其他設定 → 匯出 JSON**

可以先輸入檔案名稱，再將目前作品儲存成 JSON。

JSON 會保存：

- 畫布尺寸
- 拼豆位置
- 拼豆顏色
- 整格 / 半格設定
- 目前使用到的色盤資料

適合用來保存尚未完成的作品。

## 載入 JSON

點擊：

**其他設定 → 載入 JSON**

選擇之前儲存的 JSON，即可繼續編輯。

---

# 🖼️ PNG 圖片輸出

點擊：

**其他設定 → 匯出 PNG**

輸出前可以設定：

- 檔案名稱
- 自動裁切 / 完整畫布
- 外圍留白
- 透明 / 白色 / 黑色 / 自訂背景
- 輸出倍率
- 是否顯示格線
- 是否保留拼豆立體效果
- 是否顯示使用顏色與顆數
- 顏色統計放在左側 / 右側 / 下方 / 自動判斷
- 是否顯示 HEX 色碼

預設會依照實際使用到的拼豆範圍自動裁切，因此即使建立 30 × 30 畫布，也不會強制輸出整個空白畫布。

# ⌨️ 快捷鍵

## 工具

| 功能 | 快捷鍵 |
|---|---|
| ✏️ 上色 | `D` |
| 🧽 擦除 | `E` |
| 🪣 填滿 | `F` |
| 🎯 吸色 | `I` |
| ⬚ 框選 | `S` |
| ↩️ Undo | `Ctrl + Z` |
| ↪️ Redo | `Ctrl + Y` |

macOS 可使用 `⌘` 取代 `Ctrl`。

## 吸附

| 功能 | 快捷鍵 |
|---|---|
| 整格吸附 | `1` |
| 半格吸附 | `2` |

## 框選操作

必須先選取至少一顆拼豆。

| 功能 | 快捷鍵 |
|---|---|
| 左移 0.5 格 | `←` |
| 右移 0.5 格 | `→` |
| 上移 0.5 格 | `↑` |
| 下移 0.5 格 | `↓` |
| 左移 1 格 | `Shift + ←` |
| 右移 1 格 | `Shift + →` |
| 上移 1 格 | `Shift + ↑` |
| 下移 1 格 | `Shift + ↓` |
| 複製選取 | `Ctrl + D` |
| 刪除選取 | `Delete` / `Backspace` |
| 水平翻轉 | `H` |
| 垂直翻轉 | `V` |
| 取消選取 | `Esc` |

macOS 的複製選取可使用 `⌘ + D`。

# 📱 手機使用

介面會依照螢幕寬度自動調整，因此可以直接使用手機瀏覽器開啟。

目前已針對桌面與手機版介面進行基本調整。

由於手機沒有滑鼠右鍵與實體鍵盤，因此部分桌面快捷操作在手機上不適用，主要透過畫面上的工具按鈕操作。
